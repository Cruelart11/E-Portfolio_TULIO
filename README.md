# Justine Bradley Tulio — E-Portfolio

A personal academic e-portfolio created to present my course expectations, exercises, written works, reports, notebooks, supporting files, and learning reflections.

## Live E-Portfolio

Visit the deployed portfolio:

**[https://cruelart11.github.io/E-Portfolio_TULIO/](https://cruelart11.github.io/E-Portfolio_TULIO/)**

## About the Project

This e-portfolio was created for my academic activities and assignments. It provides an organized place where my professor and adviser can review my submitted work, supporting documents, and reflections.

The portfolio currently includes:

- Personal profile and About Me section
- Course expectations
- Adviser questions and answers
- Prelim exercises and written works
- Midterm exercises
- IEEE reports
- Google Colab and Jupyter notebooks
- Excel workbooks and training logs
- Descriptions and learning reflections for each activity

Additional coursework will be added as the semester progresses.

## Features

- Responsive desktop and mobile design
- Terminal-inspired visual theme
- Separate pages for each academic term
- Clickable and collapsible activity folders
- Embedded PDF previews
- Read-only notebook previews
- Read-only Excel workbook previews
- Direct PDF and workbook downloads
- Google Colab integration
- Accessible navigation and semantic headings
- Automatic deployment through GitHub Actions
