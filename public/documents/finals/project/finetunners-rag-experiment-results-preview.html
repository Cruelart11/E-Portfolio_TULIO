21CPU-to-GPU Speedup
22This table presents the CPU-to-GPU speedup for each configuration. Response-time speedup was calculated by dividing the CPU average response time by the corresponding GPU average response time, while indexing speedup was calculated by dividing the CPU indexing time by the GPU indexing time. A value greater than 1 indicates that the GPU completed the task faster than the CPU. Configuration E achieved the highest response-time speedup at 63.11 times, while Configuration D achieved the highest indexing speedup at 11.48 times. Configuration C was still selected as the recommended configuration because it combined a 57.63-times response speedup with the strongest observed answer quality.
